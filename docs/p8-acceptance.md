## 验证边界

支持账号有权观看、平台实际返回的普通 SDR DASH / AAC。真实 DRM、单独付费、其他地区或网络、HDR / 杜比视界与 60fps 仍需对应样本；不能把账号大会员有效当作全部内容的授权。没有永久下载、自动连播或自动跳片头片尾。

本次六集均未返回独立 CC 数据，因此验证的是无 CC 时正确提示与正常观看；独立字幕的原生渲染使用合成 SRT，不能据此声称已验收真实番剧 CC。普通 1080P 与高码率对比、代理隔离和用户确认的国内关闭 VPN 条件见 P8-A 记录；P8-B 重测了正式流程的直连实播，没有新增另一运营商或另一地区实测。未在另一台无 Python 的干净机器重复安装验收。
