# 本地直播 0.5.4-p4 · Qt 功能版

P4 完成原有直播工作流向 Qt 的迁移。使用外部 64 位 PotPlayer 播放，两平台取流、画质、房间管理、账号与诊断共用已验证的业务模块。

## 启动与数据

完整解压 ZIP，运行文件夹内 LiveViewer-0.5.4-p4.exe，保留 runtime。无需安装 Python。在“设置”选择已安装的 PotPlayerMini64.exe，例如 D:\potplayer\PotPlayerMini64.exe。

数据保存在 EXE 同目录 data。升级前关闭旧工具并保留备份，把旧版 data 复制到新 EXE 同目录即可恢复收藏、历史、播放器路径、画质与账号使用偏好。加密登录只对原 Windows 用户可解密，账号可能已经过期；启动不自动播放。P2 / P3 的程序包继续保留。避免同时用两个工具写同一个数据目录。

源码默认入口为 main.py，qt_main.py 仍可用；安装 requirements.txt，执行 python main.py，或双击 Start-Live-Viewer.cmd。Tk 入口保留为 legacy_main.py。源码默认使用 .local，可传 --data-dir 选择独立目录。

源码构建：创建 .venv-p0 并在其中安装 requirements-qt-build.txt，执行 python tools/build-p4.py。包内 source 提供相同应用源码、依赖文件和构建脚本；Qt 共享库与许可证单独保留。

## 观看与房间

输入 B 站 / 斗鱼房间号或直播间链接，选择匿名 / 已登录账号和画质，开始播放。播放器保持独立窗口；工具显示接口实际返回画质，平台降档会明确标记。

开始播放或诊断画质对比后，可用档位加入画质下拉框；选择后重新开始播放。以实际返回画质和采样结果为准，接口标称码率不保证每秒都有同样数据量。

收藏索引为平台 + 数字房间号，名称可自由修改。单击收藏 / 历史填入输入框，双击播放。历史仅在收到媒体数据后记录，最多 30 个房间。编辑待播放房间不改变当前播放或重连目标。

暂停后继续、回到直播会重新获取最新直播。主动停止、在 PotPlayer 关闭播放或关闭窗口会取消自动恢复。退出工具会关闭其专用播放器；原有独立播放器不受控制。

## 账号、扫码与记忆

在“账号”选择对应平台的“扫码登录”，用该平台手机 App 扫码并确认。程序先接收 Cookie，再检查登录；B 站能验证有效性，斗鱼 Cookie 的账号有效性尚未独立验证。

二维码、登录网址和扫码密钥仅保留在内存。刷新、取消、关闭、清除登录后，旧扫码结果不会导入。登录流程与播放任务独立。

“记住此平台登录”默认关闭。关闭时新登录只用于本次会话；开启后，现有或之后扫码 / 导入的有效登录由 Windows 当前用户加密保存。新登录会替换旧加密记录。关闭记忆会删除保存的登录，本次内存登录仍可用；“清除登录”同时清除内存、保存的登录与待完成的扫码 / 验证任务，并停止该平台正在使用已登录账号的直播。

“检查登录状态”可重新验证。若确认 B 站会话已过期，工具清除该登录并停止其账号播放；网络检查失败不会把旧登录直接当作失效。

仍支持 Netscape Cookie 文件（有无后缀均可）或密码样式输入框粘贴单行 Cookie。B 站可粘贴 SESSDATA 的值，斗鱼可粘贴请求标头的 Cookie。Edge / Chrome 的无后缀 Cookies 是 SQLite 数据库，不能作为文本导入，修改后缀也无效。

## 诊断与报告

诊断对象可选观看页输入的房间，或当前 / 上次播放会话；每次任务固定自己的房间、画质与网络方式。检查不会启动播放器。

- “检查连接”：分别检查登录（如选用）、房间 / 播放接口和 CDN FLV 读取，显示失败阶段。
- “对比匿名 / 登录画质”：依次采样两个会话，显示实际画质、元数据尺寸 / 帧率及短时采样码率；没有账号时明确跳过登录对比。
- “取消检查”：阻止继续采样和结果更新。已经开始的网络请求可能要等超时结束；界面仍可操作。
- “导出诊断报告”：保存连接结果、匿名 / 登录对比、当前 / 上次实播的播放器反馈、重试及转发统计，以及用户确认的画面声音和观察备注。

短时采样只验证容器与媒体数据，不能代替画面与声音确认，也不测量相对平台官网的直播延迟。接口返回的帧率和实际播放器反馈分别记录。停止后仍可导出上次播放的统计。

报告使用字段白名单与脱敏，不包含 Cookie、扫码密钥或完整签名媒体地址。请勿分享 data/credentials。

## 事件与故障

所有活动按 DEBUG / INFO / WARN / ERROR / CRITICAL 落盘。重要故障使用统一固定告示，首次 ERROR 提供非阻塞提醒，确认不会清除尚未解决的故障。通知可进入日志或连接检查。

普通账号 / 诊断成功不清除播放故障。未开播为 WARN，主动停止为 INFO，重试不逐次要求确认。日志支持筛选、搜索、详情、复制与脱敏导出。

后台 / 全屏提醒可见性、长时间稳定性、RTX 5060 / 1440p 的 NVIDIA 视频超分和正式发行检查在 P5 继续；B 站点播在 P6 实施。
