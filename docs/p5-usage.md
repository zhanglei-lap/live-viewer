# 本地直播 0.6.0 · Qt / PotPlayer 直播版

P5 增加 PotPlayer 原生进度条回看、NVIDIA 视频超分选项、后台提醒与资源清理，保留两平台取流、扫码、加密记忆、收藏、历史及诊断报告。

## 安装与升级

完整解压 ZIP，运行 LiveViewer-0.6.0.exe，保留 runtime 目录。播放器选择已安装的 64 位 PotPlayerMini64.exe。关闭旧工具后，把原 data 文件夹复制到新 EXE 同目录，即可恢复设置及同一 Windows 用户保存的登录；建议保留旧包与数据备份。

源码入口 main.py 或 qt_main.py，依赖 requirements.txt。默认使用 .local，也可传入 --data-dir。构建脚本 tools/build-p5.py，构建依赖 requirements-qt-build.txt。

## 原生缓存回看

设置中的“使用 PotPlayer 原生进度条回看直播”默认开启，最长范围可选 10–300 分钟。播放器进度条会出现已接收的时间范围，直接拖动或使用其跳转快捷键回看。

回看模式把取得的原编码 FLV 数据通过仅绑定 127.0.0.1 的 RTMP 连接交给 PotPlayer，以使用它的原生流媒体时移；不重新编码视频。关闭回看时保留原 HTTP-FLV 播放路径。

暂停后继续保持暂停位置；“回到直播”跳到当前已接收的末端附近，不主动重新解析房间。CDN 正常结束输入连接时，会刷新输入并保持原生回看连接与连续时间戳。切换房间、画质、回看设置或超分设置会建立新会话；输入无法恢复或播放器故障时，重建专用播放器会话，旧回看范围可能丢失。不能回看程序开始接收之前的内容。

原生时移由 PotPlayer 管理，本机实测主要使用播放器内存。300 分钟是配置上限，实际范围还受码率、内存及播放器行为影响；4 Mbps 压缩数据五小时约 9 GB，解码与渲染还需其他资源。内存不足时工具停止回看会话并提醒，建议选择与可用内存相符的范围。

专用播放器的临时目录隔离在 data/cache/live 的独立会话目录；正常关闭播放器或退出工具会清理该目录。播放器组件缓存 data/potplayer/engines 与设置保留，便于之后启动。它们不属于直播视频缓存。点击停止关闭当前媒体，播放器窗口可保留；关闭窗口后其进程资源释放。

回看模式使用持续输入，不使用原实时转发的短时积压断开策略；关闭回看后，才可启用“优先实时播放”选项。

## NVIDIA 视频超分

设置中的“NVIDIA 视频超分”对本工具专用 PotPlayer 配置启用内置 D3D11 渲染器和 GPU 超分，下次播放生效。默认关闭，不更改原 PotPlayer 配置或系统驱动设置。

本机 RTX 5060、驱动 617.42、2560×1440 显示器已完成 720p / 1080p 与 30 / 60fps 测试图的开关对比。视频必须实际显示并放大；隐藏、最小化或缩小视频时，不应据此判断超分激活。直播画面与素材不同，效果及 GPU 占用会变化。

诊断页显示“已请求”而非保证所有视频当前均已激活。可结合播放器渲染信息、NVIDIA App 状态和同画面开关对比判断。GPU 忙碌本身不是激活证明。该技术是视频 VSR，与游戏 DLSS 不同。适用条件参见 [NVIDIA 视频超分说明](https://nvidia.custhelp.com/app/answers/detail/a_id/5448)；PotPlayer 内置渲染器的支持见 [官方更新记录](https://t1.kakaocdn.net/potplayer/PotPlayer/v4/Update2/UpdateEng.html)。

## 后台与全屏提醒

故障始终进入日志和固定告示。主界面在前台时使用非阻塞提醒窗口；在后台时请求 Windows 系统提醒，并保留未读提醒与托盘入口。点击系统提醒、托盘或“未读提醒”可返回工具。

Windows 勿扰及其他通知设置可能抑制弹出，故障不会因此被标为已解决。确认只标记已读，恢复或结束对应会话才清理当前故障；日志仍保留。

## 日常功能

账号页提供两平台扫码、Cookie 导入、登录检查和 Windows 当前用户加密记忆。B 站可验证登录有效性；斗鱼账号有效性尚未独立验证。二维码与扫码密钥不落盘，刷新 / 取消后的旧结果不导入。

收藏按平台 + 房间号索引，名称可改，历史最多 30 个实际取到数据的房间。诊断支持接口 / CDN 检查、匿名与登录会话画质对比、取消及脱敏报告；不把容器采样当作画面、声音或平台相对延迟的自动验证。

本版仍以直播为范围，B 站点播在 P6 继续。
