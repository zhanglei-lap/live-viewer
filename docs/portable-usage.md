# 本地直播 0.5.0

适用于 Windows 11 x64，无需安装 Python。完整解压便携 ZIP 后双击 LiveViewer-0.5.0.exe；保留同目录 runtime 和原有 data 文件夹。

1. 在“观看”页选平台、输入房间号或链接，播放方式选“内置播放器”，点击“开始播放”。默认无需安装 PotPlayer。
2. 内置播放器使用 mpv 自己的窗口和悬浮控制条。空格暂停 / 继续，F 或双击全屏，Esc 退出全屏，L 或“回到直播”重新连接；底部缓存条支持本次观看缓存内的点击 / 拖动回看，左右键移动 5 秒。没有整场直播的历史进度。暂停后继续播放会重新连接最新直播位置。
3. 在“自定义房间名”填入名称并点击“保存房间”；以后选中收藏，点击“播放收藏”。名称按平台＋房间号保存，改名不会改变房间索引，并同步最近观看。
4. “最近观看”记住最近 30 个实际取到视频数据的房间。上次房间、画质和播放方式都会保存，启动不会自动播放。
5. 在“账号与播放器”页点击“扫码登录”，使用对应手机 App 扫码确认。成功后选择登录会话播放；也可导入或粘贴本机 Cookie。
6. “记住当前平台登录”默认关闭，勾选后使用 Windows 用户加密保存。取消勾选删除已保存登录，本次会话仍可用；清除登录同时清除内存和保存内容。
7. “内置播放器断流后自动重连”默认开启。断流时显示倒计时并自动重新取流，最多退避至每 30 秒一次，不追加旧源，也不弹出确认框。停止播放、关闭播放窗口、退出或暂停会抑制重试。可取消勾选关闭自动重连。
8. “回到直播”使用当前会话的房间和画质重新连接。“优先实时播放”减少转发积压，下次播放生效；显示的转发进度差和缓存时长都不等于画面相对主播的绝对延迟。
9. 若需要继续使用 PotPlayer，在观看页选择 PotPlayer，并在账号页指定程序路径。PotPlayer 自身的旧源列表和错误弹窗行为仍由外部播放器控制。
10. “画质对比与报告”查看实际返回档位并导出报告。平台可能降档，本机播放器不会提高源流码率。
11. “账号与播放器 → 网络连接”默认直连，不继承系统 / 环境代理；也可选择系统 / 环境代理。更改后重新开始播放生效。VPN 全局隧道由 Windows 控制。朋友不开 VPN 无法观看时，选直连，再运行“检查当前直播间连接”，并导出报告；提示区分接口与 CDN、DNS / TLS / 代理 / 超时。内置播放器的本机连接始终绕过环境代理。
12. 直连优先 IPv4，失败后仍回退 IPv6；系统 / 环境代理保留系统地址排序。该调整不更换 DNS、不修改 Windows 网络设置。

EXE 同目录 data 保存收藏、历史、设置和选择记住的加密登录；更新程序前关闭工具，保留 data。不要分享 data/credentials。完整引擎位于 runtime/mpv，附有来源、摘要和 LGPL 许可证；只拷贝 EXE 会缺少内置引擎。

二维码和密钥不写入磁盘。报告不含 Cookie、签名直播地址或本机播放地址；备注按原文导出，请勿填入凭据。B 站播放前检查登录，斗鱼账号有效性尚未独立验证。

当前平台解析只提供 AVC HTTP-FLV。内置引擎已做短时实播和受控断流恢复验证，长时间播放、实际声音与音画同步仍需本机验收；网络恢复包含重新开流间隔，不承诺无缝。
