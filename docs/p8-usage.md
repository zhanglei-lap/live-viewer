# 本地直播 0.9.0 · 番剧点播

完整解压便携包后运行 `LiveViewer-0.9.0.exe`。PotPlayer 仍需单独安装，路径在“设置”页选择。保持整个 runtime 目录与 EXE 同目录。

也可使用独立的 `LiveViewer-0.9.0-single.exe`，单独复制即可启动；原文件夹版 EXE 不能脱离 runtime。单文件版的启动、迁移及验证说明见 [单文件版说明](p8-single-usage.md)。

## 番剧入口

1. 打开左侧“B 站番剧”，输入 `ep693247`、`ss43164` 或 B 站 `/bangumi/play/ep…` / `ss…` 链接，点击“获取番剧”。裸数字作为 EP 编号。
2. 季度 / 版本下拉框显示平台提供的相关版本；剧集列表分别标出正片、预告和附加内容。每集有平台会员 / 付费标记、EP 编号及上次进度。
3. 选择剧集，程序查询当前会话资格。匿名可能只获试看；平台列出高清选项不代表已经返回对应媒体。只列出本次账号真正返回的普通 SDR DASH 与 AAC 轨道。
4. 会员观看选择“使用已登录 B 站账号”。可直接点击“扫码登录”，在手机 App 确认；登录记忆仍由“账号”页控制。切换账号、网络或剧集后重新检查，旧结果会被丢弃。
5. 选择实际画质、编码和音轨，点击“播放当前集”。在 PotPlayer 原生播放条拖动回看，使用固定底部的暂停、停止和恢复按钮。暂停恢复保留本集位置；重连重新使用番剧接口，不将 EP 转成普通 BV 投稿播放。

不同账号的会员、地区和单独付费资格均以平台对本集的结果为准；没有本地强制会员或 DRM 解密功能。下架、未上线、试看和权限问题会进入活动日志并显示统一告示。画质取决于实际返回轨道；4K 不是所有作品都提供。

## 收藏、历史与继续观看

- “收藏作品”以 season_id 去重，可在右侧输入自定义名称，左侧改名会同步该作品的历史名称。相同名称可以属于不同季度。
- 双击收藏进入对应季度，优先定位上次保存 / 观看的 EP。剧集历史以 EP / cid 去重，双击历史定位原集；内容标识变更会停止恢复，避免播放另一集。
- “从本集上次位置继续”启用时恢复该 EP / cid 的进度和仍可用的轨道选择；已看完的集从头播放。关闭选项可从头重新看。本版手动选集，未加入自动连播或自动跳片头片尾。
- 直播、普通视频与番剧记录分别保存，番剧不会写入 BV 收藏或房间历史。取消、停止和关闭会废弃迟到的后台结果。

## 字幕与通知

画面原本包含的字幕会随视频正常播放。“查询 CC 字幕”用于平台额外提供的字幕文件，没有返回 CC 数据时不影响观看。切集后清除上一集字幕选择；字幕 URL、正文和临时媒体地址不进入收藏或诊断报告。所选字幕不可用时提供错误告示，可关闭 CC 后重试。

活动日志新增“番剧”来源，可与播放器、账号及其他活动一起筛选。试看 / 权限受限阻止播放时会有醒目告示；一条 CDN 失败但仍可恢复时记录尝试，恢复最终失败再显示故障。告示不会被无关的账号成功消息覆盖。

## 升级与资源

0.8.0 稳定包保留。升级时先退出程序，可把旧便携目录的整个 data 文件夹复制到新 EXE 旁；复制前保留旧目录。直播和普通视频收藏、历史、设置及断点保留，番剧增加自己的数据项。DPAPI 登录记忆仍绑定当前 Windows 用户，在另一台机器应重新扫码。

源码默认数据目录为项目 `.local`；便携 EXE 为其旁的 `data`。验证必须明确指定独立 `--data-dir`，不使用正常账户数据。发行 ZIP 不包含个人数据、Cookie、报告或 PotPlayer 本体。

停止结束本机转发与自动恢复；关闭程序清理本工具的专用播放器、临时缓存和本轮配置，不操作用户另开的 PotPlayer。可复用的引擎副本留在 data/potplayer/engines，这不是整集下载缓存。

匿名验收命令（源码）：

```powershell
.venv-p0\Scripts\python.exe qt_main.py --data-dir .research/p8-anonymous-app --probe-p8 .research/p8-anonymous-app.json
```

会员验收必须在可见窗口由用户扫码确认，使用独立目录。可以加 `--probe-p8-member --probe-p8-full`，完整播放首集并检查切集、续期、暂停恢复和断点。工具等待扫码时可刷新二维码或关闭窗口取消。
