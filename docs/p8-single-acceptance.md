# 0.9.0 单文件版验收

日期：2026-10-14。范围：将已验证的 P8-B 文件夹版打包为独立 Windows 11 x64 EXE，解决只复制原 EXE 后找不到 `runtime/python314.dll` 的启动错误。

## 交付与结论

交付文件：`dist/p8-single/LiveViewer-0.9.0-single.exe`，48,844,773 字节（约 46.6 MiB）。SHA256：`88074e3c625d52a908af428b0c6ac54b42ceacebe7a3de4becddf0512728fb06`。

单独复制此 EXE 即可启动，不需要外置 runtime、Python 或 Qt。PotPlayer 仍按原设计单独安装；设置和收藏保存在 EXE 旁的 data，Windows 加密登录不能随 EXE 自动迁移到其他电脑。

原文件夹版 EXE、ZIP 与个人 data 保留。文件夹版仍需完整 runtime；其 ZIP SHA256 为 `f85bc9e864d47aaf49e1cea667efe05ce037a4ebb7e770d4f44696289f029a3c`，本次未修改。

## 验证环境与结果

将最终 EXE 单独复制到带中文与空格的新目录，工作目录使用另一个空目录；子进程 PATH 仅含 Windows 与 System32，删除 Python / Qt 相关环境变量，TEMP / TMP 指向独立中文目录。所有账户和设置使用新建测试数据，未读取正常登录。

| 业务代码对应 | `PYZ.pyz` 和 `qt_main` 与已验收文件夹版逐字节相同 |

| 启动与退出的临时依赖 | 通过；各次正常退出后 `_MEI` 目录清理 |

最终报告为 `.research/p8-single-validation.json`，记录二进制摘要与各独立测试结果。普通视频和番剧均在上述隔离环境由最终单文件 EXE 运行；不是只验证压缩包存在。会员实播沿用 P8-B 的已确认记录，本次没有重新使用真实账号扫码，不能声称单文件版重复了会员整集测试。

## 对照发现的既有问题

额外运行旧 P6 普通视频探针时，其“将第二分 P 定位至最后一秒”的检查在单文件版和原文件夹版都出现 `vod.ended_early`，播放器结束后程序未识别为正常完成。两份原始失败记录保留：`.research/p8-single-initial-validation.json` 对应单文件报告，以及 `.research/p8-folder-vod-control.json`。

本次没有改动播放逻辑，也没有把这项失败改写为成功。该边界问题待后续修复；单文件打包结论限定为独立启动、依赖完整性及上表已通过的页面 / P7 / P8 回归，不等于所有播放行为均无问题。

## 分发与边界

说明和源码 / 许可证可随完整单文件便携 ZIP 一起分发；运行只需要其中的单文件 EXE。对应源码与许可证也嵌入 EXE 的 release 资源。分发文件不包含个人 data、Cookie、扫码密钥或 PotPlayer 本体。

另一台 Windows 11 的原始失败条件已由用户确认是“只复制了文件夹版 EXE”。本机隔离启动验证覆盖这一条件，但仍需在该机器使用新单文件 EXE 复测；未使用另一台干净机器或 Windows Sandbox 验收，不承诺其他系统版本、架构或全部地区网络。
