# 本地直播 0.5.3-p3 · Qt 功能预览

适用于 Windows 11 x64，以外部 64 位 PotPlayer 播放。P3 完成 Qt 观看、收藏 / 历史、设置和活动日志页，接入 P1 / P2 的真实事件、取流和专用播放器控制。

## 启动与升级

完整解压 ZIP，运行 LiveViewer-0.5.3-p3.exe；保留相邻 runtime 目录。无需安装 Python。在“设置”选择 PotPlayerMini64.exe，例如 D:\potplayer\PotPlayerMini64.exe。

首次启动不会播放。数据保存在 EXE 同目录 data 中。退出 P2 后，可以把其完整 data 文件夹复制到新 EXE 所在目录，恢复收藏、历史、设置与同一 Windows 用户加密保存的登录。首次迁移前保留原文件备份；不需要复制旧播放器缓存与日志即可恢复主要设置，但 credentials 必须保留才可恢复记住的登录。两个版本分别保留自己的程序包，避免同时运行并写入同一数据目录。

源码运行：安装 requirements-qt.txt，然后执行 python qt_main.py。源码仍使用项目的 .local 目录。也可以传入 --data-dir 指定隔离目录。

构建：在项目或随包提供的 source 中建立 .venv-p0，使用该环境安装 requirements-qt-build.txt，执行 python tools/build-p3.py。构建依赖与运行依赖分开，脚本只输出 dist/p3，不读取个人登录。

## 观看

1. 选择平台，输入数字房间号或直播间链接，选择匿名或已登录账号，点击“开始播放”。
2. PotPlayer 在专用独立窗口播放。主界面显示当前会话与实际返回画质。接口列出的可选画质会加入下拉框，选好后重新开始播放；平台可能降档，以实际画质为准。
3. “暂停 / 继续”和“回到直播”操作当前会话；继续会重新取得最新直播。编辑输入框不会改变正在恢复的房间。
4. 工具的停止、PotPlayer 内主动关闭播放或关闭窗口都会取消自动恢复。退出工具会关闭其专用播放器；原本自己打开的播放器不受控制。
5. 收藏以平台 + 房间号为索引，自定义名称可重复，同房间保存会改名。双击收藏 / 历史播放，单击只填入输入框。历史仅在收到媒体数据后记录，最多 30 个房间。

P2 已验证的专用配置、同一地址替换源与受控恢复策略继续使用。工具不附带 PotPlayer 本体；专用实例使用独立配置，不导入原播放器的个人历史。

## 事件与提醒

活动按 DEBUG / INFO / WARN / ERROR / CRITICAL 分级落盘。未开播等阻止启动的事件显示固定告示；连接 / 播放器故障首次显示非阻塞提醒窗口，可在设置中关闭窗口提醒，固定告示与日志仍保留。确认提醒不会把故障标为已解决。

告示跨页面保留，普通登录成功与保存消息不会覆盖播放故障。恢复成功、开始新会话或主动停止清除对应播放告示。主动停止为 INFO。相同会话的重复重试记录日志，不逐次要求确认。全屏与后台系统通知的实际可见性留到 P5 验收。

日志支持同时按等级、来源、目标和内容 / 事件 / 会话搜索；点击事件查看详情，复制详情或导出当前筛选结果。导出不包含 Cookie、二维码密钥及完整签名媒体地址。界面展示最多最近 2,000 条；原始轮转 JSONL 在 data/logs 中，单文件上限 2 MiB，每次运行保留两份轮转，最多保留五组运行日志。

## P3 账号与后续功能

P3 支持恢复先前加密记住的登录、导入 Netscape Cookie 文件（有无后缀均可）、密码样式输入框粘贴 Cookie，以及清除登录。新导入的 Cookie 只用于本次会话。若此前已记住登录，P3 仍保留此前的加密记录，下一次恢复的还是此前保存的登录；要替换记住的登录，可在 P2 操作或等待 P4 登录记忆管理。

Edge / Chrome 的无后缀 Cookies 是 SQLite 数据库，不能作为文本导入。B 站播放前检查登录，斗鱼账号有效性仍未独立验证。

P4 将完整迁移扫码登录、登录记忆开关、网络连接检查与画质对比报告。P3 诊断页提供当前播放器的状态、尺寸与进度，不把这些反馈等同于自动核验解码画面或声音。NVIDIA VSR、点播和全屏 / 后台通知继续按路线推进。
