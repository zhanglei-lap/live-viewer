# 本地直播 0.5.2-p2 · PotPlayer 接管版

完整解压 ZIP 后运行 LiveViewer-0.5.2-p2.exe。无需安装 Python；需要已安装 64 位 PotPlayer。在“账号与播放器”页选择原安装目录中的 PotPlayerMini64.exe。

1. 在观看页选择 PotPlayer，输入房间号或打开收藏，点击开始播放，程序创建专用播放窗口。
2. 首次使用会从安装目录准备本地运行副本与独立配置；后续复用缓存。原播放器安装文件、普通窗口和原有配置保持独立。专用窗口的皮肤与渲染设置可以自行调整并保留。
3. 回到直播或自动恢复会重新取得直播源，保持相同本机播放地址，并重开当前项；更换房间也复用专用窗口。
4. 勾选直播断流后自动重连时，意外断流会按退避策略重新连接。暂停时不恢复；继续时回到最新直播。工具停止、PotPlayer 关闭播放（F4）或关闭窗口，会取消恢复。
5. 播放器控制不兼容、超时、房间未开播或登录失效等情况会明确提示，需要处理原因后手动重试。专用窗口的媒体错误确认框关闭，取流故障由工具固定告示、非阻塞提醒与日志呈现。
6. 控制只关联本工具创建的进程及窗口；在专用窗口打开其他内容后，本工具停止自动恢复直播。
7. 账号、扫码、登录记忆、房间命名、收藏、历史、画质对比、网络设置和日志功能沿用 P1。

升级前退出程序，将原 data 文件夹复制到新 EXE 旁，保留设置、收藏和登录。data/potplayer 保存运行缓存与专用播放器偏好；请勿分享 data/credentials。发行包不包含个人数据或 PotPlayer 运行文件。

此包以 PotPlayer 为主，不携带 libmpv。原内置播放器为可选组件，需要时可保留原包的 runtime/mpv 文件夹。Qt 页面替换在 P3，RTX 视频超分验证在 P5。

程序依播放器返回的状态、尺寸和持续播放进度判断播放活动；实际画面、声音与音画同步由使用者确认。恢复有重新取流和加载间隔，不承诺无缝。

离线检查：LiveViewer-0.5.2-p2.exe --self-test 检查结果.json。检查使用合成数据与临时目录，不启动 PotPlayer，不读取个人账号。
