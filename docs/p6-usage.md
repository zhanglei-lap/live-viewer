# 本地直播 0.7.0 · B 站点播预览

P6 增加普通 B 站视频播放、分 P、可用音视频轨选择与视频收藏，保留 P5 的直播、原生回看、扫码、账号记忆、通知和 VSR 选项。

## 安装与升级

完整解压 LiveViewer-0.7.0-win-x64.zip，运行文件夹中的 LiveViewer-0.7.0.exe，保留 runtime。使用已安装的 64 位 PotPlayer，例如 D:\potplayer\PotPlayerMini64.exe。

关闭旧工具，备份原 data 文件夹，再复制到新 EXE 同目录。原直播收藏、历史、设置与同一 Windows 用户保存的加密账号继续使用。视频收藏保存在新增字段；退回旧版时使用对应数据备份，旧版保存设置会丢弃不认识的新字段。

源码入口 main.py / qt_main.py，依赖 requirements.txt。Build-Live-Viewer.cmd 或 tools/build-p6.py 构建当前版本。便携包不含个人数据、账号或 PotPlayer 本体。

从包内 source 重新构建时，在 source 目录执行：

```powershell
python -m venv .venv-p0
.\.venv-p0\Scripts\python.exe -m pip install -r requirements-qt-build.txt
.\.venv-p0\Scripts\python.exe tools/build-p6.py
```

## 播放 B 站视频

1. 打开“B 站视频”页，输入 BV 编号、av 编号或 https://www.bilibili.com/video/BV… 链接，点击“获取视频”。链接中的 p 参数会选择对应分 P。
2. 匿名模式可直接获取；使用账号时先在“账号”页扫码登录 B 站，再选择“使用已登录 B 站账号”，重新获取画质。
3. 选择分 P、视频画质和音频音质。切换分 P 后自动查询其实际可用轨道。本版选择 AVC 视频与 AAC 音频，不把平台宣传的未授权档位作为可选项。
4. 点击固定在页面下方的“播放视频”，通过 PotPlayer 原生进度条拖动。暂停后从原位置继续，视频播完不会被直播重连策略重新启动。
5. 直播与视频共用一个当前播放会话；播放另一个视频、分 P 或直播时会关闭旧专用实例。停止关闭媒体和本机服务，关闭窗口或退出工具释放专用进程和临时目录。

播放地址到期、轨道不可用或读取失败时，事件进入日志和固定告示，并按影响使用强提醒。视频页可“重新获取并播放”；P6 重新开始播放，自动刷新并保留进度在 P7 完善。

## 视频收藏和历史

获取视频后填写“收藏名称”，点击“收藏当前分 P”。收藏使用 BV + cid（分 P 内容编号）索引，名称可随时修改；重复保存更新同一项。BV / AV 会经元数据统一为 BV。

左侧提供收藏、最近观看、搜索、改名和删除。双击已保存视频会重新解析并播放，不保存临时 CDN 链接。分 P 顺序改变时按 cid 寻找原内容；原 cid 不再存在时告知重新选择，不自动播放其他内容。

视频历史最多 30 项，与直播房间历史分开保存。取得本机转发数据后记录，不把仅查询信息计为已观看。P6 不保存断点播放时间。

## 播放链路与资源

普通视频元数据 → WBI 播放接口 → 当前账号实际可用的 AVC / AAC 轨道 → 本机 HTTP 字节范围服务 → PotPlayer 视频地址 + /aud 独立音轨。

平台接口与签名都在本机完成，沿用直连 / 系统代理设置。播放器只取得 127.0.0.1 的会话地址；本机服务校验私有会话令牌和固定路径，转发 HEAD、单一字节 Range、206、Content-Range 与准确长度，限制并发。上游 HTTPS 保持证书验证，重定向限制在已支持的 B 站 CDN 域名。平台 Cookie 只送往平台 API，不送往 CDN 或播放器。

Python 服务按需读取，不重编码、不把完整视频保存到磁盘。PotPlayer 自己管理播放缓冲；专用临时目录继续位于 data/cache/live，正常退出清理。视频的总时长不是直播缓存范围，直播五小时回看选项不作用于点播。

诊断报告保留内容编号、实际轨道、码率标称值、播放器状态和本机转发统计，剔除 CDN 地址和凭据。活动来源“视频”可筛选；停止、自然播完、未授权或过期等事件有不同等级。

## 验证范围

本机已用 BV17x411w7KC 的两个分 P 验证双轨播放、AAC 解码器与音频渲染链、前后拖动、60 秒暂停继续、收藏与历史、切换实例和退出。匿名抽样得到 360P，第一分 P 实际 512×288，第二分 P 640×360；不能将此抽样当作所有视频的匿名上限。

测试保持静音；声音听感、主观音画同步和真实账号的更高画质请在正常观看中确认。渲染链证据不等同于人工听感验证，标称帧率也不是掉帧测量。

本版限定普通、当前账号可访问的标准投稿。番剧 / 课程、交互视频、试看片段、DRM、永久文件下载和更多编码尚未纳入本次交付。签名地址自动续期、断点续播、字幕与长期暂停覆盖在 P7 继续。

实现核对参考 [yt-dlp 作者的 B 站提取器](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py)，并以当前平台实际响应和本机 PotPlayer 的 CmdLine64.txt / 原生实播为准；这不是平台提供的稳定公开 SDK。

直播、超分与账号说明继续参见 [P5 使用说明](p5-usage.md)。
