# P9 抖音直播

在“观看”页把平台切到“抖音”，输入直播间链接或房间号，点击“开始播放”。
播放方式与 B 站、斗鱼一致：本机转发后交给 PotPlayer。

## 输入

支持两种写法：

- 链接：`https://live.douyin.com/67876457927`
- 房间号：`67876457927`（12–15 位数字）

不支持 `https://v.douyin.com/xxxx/` 这类分享短链，需要先在浏览器打开，
从地址栏取 `live.douyin.com/` 后面的数字。应用了支持房间号与直播页链接；
其他抖音页面（例如视频页）会被拒绝并提示。

## 画质

抖音实际返回的档位由平台决定，不是所有直播都有全部档位。本工具按标称码率排序：

| 选项 | 平台档位 | 本次实测（房间 67876457927） |
|---|---|---|
| 原画（默认） | `origin` | 1920×1080 / 59fps / 约 15.6 Mbps |
| 超清 | `uhd` | 1920×1080 / 45fps / 约 6.0 Mbps |
| 高清 | `hd` | 1280×720 / 30fps / 约 4.0 Mbps |
| 标清 | `sd` | 1280×720 / 30fps / 约 2.0 Mbps |
| 流畅 | `ld` | 960×540 / 25fps / 约 1.0 Mbps |
| 极速 | `md` | 640×360 / 15fps / 约 0.8 Mbps |

“原画优先”默认请求 `origin`；平台降档时界面显示实际档位。原画码率可能接近
16 Mbps，占用带宽较大，网络吃紧时请手动选择高清或标清。

抖音的纯音频档位（`ao`）不会出现在列表里，它不是可观看的画面。

## 登录

抖音**只支持 Cookie 导入与粘贴**，没有扫码登录。抖音网页登录链路签名复杂、
风控严格，本工具不实现扫码。

匿名即可观看大多数直播间；若某个房间匿名取流失败，可在“账号”页粘贴从浏览器
复制的抖音 Cookie 后再试。导入方式与 B 站、斗鱼相同。

抖音没有可用的登录状态校验接口，因此“检查登录状态”只会说明 Cookie 已导入，
不会声称账号已验证。

## 延迟

相对抖音网页版，PotPlayer 中的画面会稳定落后约 3 秒。已实测确认这是 **PotPlayer
内部缓冲**造成的恒定偏移，不是转发层积压：

- 转发层实测滞后 0.0 秒、队列 0.0 秒
- 播放器缓冲稳定在 3.7 秒（原生回看开）/ 5.0 秒（原生回看关），30 秒内漂移不足 0.1 秒

**不要为了降低延迟关闭「PotPlayer 原生回看」**——实测关闭后反而从 3.7 秒涨到 5.0 秒。
完整测量见 [抖音延迟调查](p9-latency-2026-11-11.md)。

网页版很可能使用抖音的低延迟协议（`lls`），本工具只转发 HTTP-FLV；FLV 链路本身
受 GOP（该房间 2 秒）限制，3–5 秒属于正常范围。

## 已知限制

- 通知与日志中的抖音记录不包含签名媒体地址；诊断报告同样只记录档位与主机名。
- 抖音接口下发的媒体地址是 `http`，工具统一升级为 `https` 再转发，
  以保持证书校验；实测同一 CDN 主机支持 https。
- 未验证：长时间播放稳定性、断流后自动重连、原生时移（回看）在抖音流上的表现。
- 抖音接口与风控可能随时变化；失效时会在活动日志给出具体状态码。

## 故障排查

| 提示 | 含义 |
|---|---|
| 该抖音直播间当前未开播 | 平台返回 `status != 2`，房间已结束或未开播 |
| 抖音未接受该房间号 | 平台返回 `4001038`，通常是房间号格式不对 |
| 抖音接口繁忙 | 平台返回 `10011`，稍后重试 |
| 抖音未下发匿名会话标识 | 未取得 `ttwid`，可能是网络或风控问题，可重试或导入 Cookie |
| 抖音未返回可供本工具播放的 FLV 流 | 该直播可能只提供 HLS，本版不支持 |

失败时点“检查连接”可在报告页看到阶段与错误分类，报告不含签名地址。
