# 本地直播 0.5.1-p1

P1 是统一事件与状态的可运行验收版，沿用当前界面与取流能力。Qt 页面迁移在 P3；P0 原型保留。PotPlayer 旧源替换、专用实例及弹窗控制在 P2。

完整解压 ZIP，双击 LiveViewer-0.5.1-p1.exe。无需安装 Python。保留 runtime 文件夹；在观看页选择 PotPlayer，在账号与播放器页选择自己的 PotPlayerMini64.exe。

- 所有操作、取流状态、候选线路失败、重连和异常经统一事件入口记录。界面底部有醒目的固定播放状态与故障告示，登录成功等普通消息不会覆盖故障。
- 未开播为 WARN 常驻告示；无法启动或断流为 ERROR 常驻告示，并提供一次非阻塞提醒。重试逐条记录，不需要逐次确认提醒。连接恢复或主动停止会清除对应告示。
- 主动停止会立即取消本次播放意图；迟到的结果不能启动播放器，也不能修改新房间状态。
- “导出事件日志”可导出最近最多 2000 条脱敏事件，包含本次尚未写入磁盘的内存事件。详细记录含时间、等级、代码、来源、房间索引和会话 ID；不包含 Cookie、二维码密钥或直播地址。
- 自动日志在 EXE 同目录的 data/logs。每次启动独立文件，一份最多 2 MiB，保留 2 个轮转文件；保留最近 5 次运行。多个仍在运行的实例不会互相覆盖或删除正在写入的文件。
- data 仍保存收藏、历史、设置及选择记住的 Windows 加密登录。升级时先关闭程序，将原版 data 整个复制到新版 EXE 旁；仅在本机保留，不分享 data/credentials。安装包不包含个人数据。
- 匿名播放、扫码登录、登录记忆、房间改名、画质对比和网络直连设置沿用原版本。现有内置播放器暂时保留；后续版本以 PotPlayer 为主。

P1 记录本工具的取流与本机转发事件。PotPlayer 已收到地址或有字节转发，都不代表程序已验证画面和声音；播放器内部状态与旧播放源处理在 P2 验证。自动重连仍沿用现有内置播放器策略，PotPlayer 需使用“回到直播”手动重连。

检查命令：LiveViewer-0.5.1-p1.exe --self-test 检查结果.json。该检查只使用独立临时目录和模拟登录数据，不读取个人账号。
