- 原生时移设置 10–300 分钟、暂停继续与原生跳转回直播；回看期间不使用三秒实时积压断开策略。已观察历史位置真实回退。
- RTMP 时间戳按媒体起点归一化；CDN 输入正常结束时刷新输入并续接时间戳，保留同一原生回看连接。包长度、AMF 嵌套和消息数量有界。停止明确关闭拥有的连接，后台读取不操作 Qt 控件。
- 回看断流恢复重建专用实例，避免旧图表的错误状态；主动关闭、停止、取消的结果不启动旧源。
- 本工具专用 D3D11 / NVIDIA VSR 设置；默认关闭，原安装配置保留。
- 进程内存与缓存范围诊断，低可用提交内存保护；临时文件隔离到 data/cache/live，退出清理，设置与程序组件缓存保留。
- 托盘、系统通知、未读提醒。记录 Windows 显示回调，通知被抑制时仍保留故障与未读入口。

### 超分受控测试

四组本地移动测试图各暂停在 1.0 秒对比同一画面；输出为 2560×1440。独立专用实例使用内置 Direct3D11 渲染器与 RTX 5060 Native D3D11 DXVA，原 PotPlayer 设置未改变。

| 输入 | VSR 关闭 GPU 占用 | VSR 开启 GPU 占用 | 关闭 / 开启功耗短时样本 |
|---|---:|---:|---:|
| 720p / 30fps | 4% | 19% | 35 / 57 W |
| 720p / 60fps | 6% | 32% | 36 / 76 W |
| 1080p / 30fps | 4% | 34% | 35 / 83 W |
| 1080p / 60fps | 8% | 64% | 36 / 124 W |

静态画面区域的配对输出平均 RGB 差异约为 9.0 / 255（720p）及 6.4 / 255（1080p）。证据来自固定帧输出差异、已核对的渲染链和配对 GPU 样本；没有独立驱动状态 API 断言，也没有把编码帧率当作掉帧测量。以上为本机短时总 GPU 样本，不是持续直播的性能保证；声音与主观效果需人工确认。

## 范围与限制

原生回看范围上限为五小时，实际还受内存和播放器行为影响。正常关闭后清理专用临时文件；异常断电产生的残留需在后续处理。缓存由 PotPlayer 管理，工具不保证跨断流或重启保留视频历史。

后台通知受 Windows 策略影响；显示回调是系统侧证据，用户仍可通过未读与固定告示查看。声音与主观画质仍需观看确认。手机扫码确认及真实账号画质差异使用 P4 工作流，账号权限与平台返回决定实际画质。
