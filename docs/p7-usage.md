# 本地直播 0.8.0 · 点播完善版

P7 增加地址自动续期、读取中断恢复、断点续播、平台字幕和 HEVC / AV1，保留普通 BV / AV / 分 P、收藏、历史、直播、扫码、VSR 与统一通知。

## 安装与升级

完整解压 LiveViewer-0.8.0-win-x64.zip，运行 LiveViewer-0.8.0.exe，保留 runtime。使用已安装的 64 位 PotPlayer。

退出旧工具，备份原 data 后复制到新 EXE 同目录。直播房间、视频收藏和同一 Windows 用户保存的加密登录兼容读取；进度存在 settings.json 的 video_progress。旧版不识别新增字段，退回旧版请使用对应数据备份。包内不含个人数据或 PotPlayer 本体。

源码 main.py / qt_main.py，构建入口 Build-Live-Viewer.cmd / tools/build-p7.py。包内 source 可重新构建：

```powershell
python -m venv .venv-p0
.\.venv-p0\Scripts\python.exe -m pip install -r requirements-qt-build.txt
.\.venv-p0\Scripts\python.exe tools/build-p7.py
```

## 续播与恢复

“B 站视频”页的“从上次位置继续”默认开启。进度按 BV + cid 保存；不会把其他分 P 的时间用于当前内容。播放时定期保存，停止、切换和退出时保存最近可验证的位置。取消勾选后从头播放；自然播完记录为已完成，下一次从头开始。

CDN 地址被拒绝或失效时，会重新查询原 cid、原视频轨与音轨，校验文件长度和前 4 KiB 的哈希，再更新同一个本机连接。播放器缓存、位置和暂停状态保留；已经收到的字节不会重复拼接。内容 / 轨道 / 初始化数据不一致时明确停止恢复，不自动降档或换分 P。

读取过程中断时从未送达的字节位置重试，单次读取最多两次。播放器持续停滞等情况下可重建专用实例，并恢复时间；自动重建最多三次，关闭自动恢复、主动暂停、停止或关闭播放器会抑制重试。暂停期间输入失败仍保留暂停状态，继续或“恢复当前视频”可重新取得原内容。

精确跳转由本工具专用配置启用；不更改原 PotPlayer 配置。恢复时间以播放器反馈为准，受媒体索引与解码器影响。恢复位置未达到目标时保留旧断点并提示，不把初始化的零秒进度当作成功续播。

日志区分正常续期、读取重试、恢复成功和最终失败；永久权限错误、账号失效、内容删除及媒体变化不会无限重试。诊断保留刷新次数与恢复位置，剔除签名地址、Cookie 和字幕正文。

## 平台字幕

获取视频后点击“获取字幕”，选择当前分 P 的字幕，再播放。字幕在下次播放生效；已保存的字幕选择可在重新查询目录后恢复。没有字幕或需要登录时会明确显示，不影响不加载字幕的视频播放。

请先在账号页扫码登录 B 站，选择“使用已登录 B 站账号”，重新获取字幕。用户指定的 BV17Ppi6dE6Y 在匿名检查中返回 need_login_subtitle=true；真实字幕内容需正常登录验证。

字幕从当前账号可访问的目录取得，JSON 转为 UTF-8 SRT，交给 PotPlayer 的原生字幕渲染器。转换限制条目数、时间和文本大小；地址与重定向限定支持的 HTTPS 域名。平台 Cookie 只送往平台 API，不送往字幕文件服务器或播放器。

SRT 临时文件保存在专用 data/cache/live 会话目录，正常关闭该播放器或退出工具清理。它不是永久字幕导出；停止保留播放器窗口时，文件留到专用实例关闭。字幕缺失或读取失败时，可重新获取或选择不加载字幕。

## 编码与画质

视频选择现在列出当前会话可用的 SDR AVC、HEVC 和 AV1；音频仍为 AAC。同一档位默认优先 AVC，用户可选其他编码。档位由账号权限和平台实际返回决定，未列出的轨道不能选择；已经选定的轨道失效时明确提示，不静默改成另一档。

本机 PotPlayer 1.7.22619.0 已完成匿名三种编码解码验证。硬件解码与 VSR 是否生效仍依播放器、显卡和实际显示条件；HDR / Dolby Vision、特殊内容、DRM 与永久文件下载没有纳入本版。

字幕合成样本已验证原生可见渲染；真实账号字幕和人工声音 / 音画同步需正常观看确认。直播回看、账号和超分用法参见 [P5 使用说明](p5-usage.md)。

接口依据包括 [提取器作者实现](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py) 与 [播放器信息接口采集](https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/video/player.md)，并以本机接口响应与原生实播为准。这些接口不是本软件获得的平台稳定 SDK。
