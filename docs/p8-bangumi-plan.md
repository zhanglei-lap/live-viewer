# P8 番剧点播开发计划

计划日期：2026-10-12。原稳定基线：0.8.0（P7）。2026-10-13 状态：P8-A 与 P8-B 均已完成，0.9.0 正式番剧入口已交付。用户指定的《孤独摇滚！》《葬送的芙莉莲》《间谍过家家》各两集真实会员实播、完整首集、暂停恢复、续期与清理通过；用户确认内容、音画与界面正常。结果见 [P8-B 验收](p8-acceptance.md) 与 [使用说明](p8-usage.md)，A 阶段独立记录见 [P8-A 验收](p8a-acceptance.md)。以下保留阶段原定范围与估算。

## 目标与实施顺序

先验证 EP 定位、会员整集取流、无系统代理播放和真实高清档位，再实现完整选集与收藏界面。继续使用 Qt / PySide6 与独立 PotPlayer，复用 P7 的双轨播放、Range 服务、地址续期和断点恢复。

本文将“解析 ep_id 的解码是否正确”分为两项：EP 标识是否定位到正确剧集，以及取得的音视频能否实际解码播放。ep_id 是剧集定位标识，不是视频编码。

| 阶段 | 工作范围 | 交付物 | 开始条件 | 增量估算 |
|---|---|---|---|---:|
| P8-A 番剧可行性验证 | EP / SS 元数据、PGC 播放解析、真实账号权益、整集判定、直连实播、高清对比与恢复抽测 | 独立验证工具、样本矩阵、脱敏结果和可行性结论 | 已完成并通过，具体覆盖见验收记录 | 1–2 人日 |
| P8-B 选集与收藏实现 | 番剧页面、季度 / 剧集列表、收藏与历史、续播、错误告示及发行回归 | 完整番剧点播入口、便携包与验收记录 | 已完成；296 项检查、正式 EXE 实播与人工音画确认通过 | 4–7 人日 |

合计约 5–9 人日，单人每天 6–8 小时有效开发；不是固定日历交付日期。遇到受保护媒体或平台接口变化时，先记录结果并重估对应范围。

## P8-A：可行性验证

### 1. 选择代表样本与官方基准

验证前确定至少三部当前账号有权观看的番剧，每部选两集，覆盖首集与中间 / 最新可看集。具体片名和 EP 链接在开始验证时确定，选择用户正在观看的番剧优先，不能仅凭历史资料假定版权和档位仍可用。

| 样本组 | 选择条件 | 主要验证点 |
|---|---|---|
| A | 一部大会员专享、普通 SDR 番剧 | 匿名受限与会员整集结果区分；首集和另一集对应正确 |
| B | 另一部具有 1080P+ 或 1080P60 档位的番剧 | 同分辨率的高码率 / 高帧率档位确实不同，实际返回轨道可播放 |
| C | 第三部具有 4K SDR 的番剧；若没有，记录未提供并选择其他高清番剧 | 高分辨率轨道、HEVC / AV1 可用性及直连读取 |
| 反例 | 未登录 / 失效登录、未上线集或账号无权观看的集 | 明确分类，不能把试看当整集；不反复无效重试 |

先记录同一账号、同一网络在官网的整集观看资格及可选档位，作为软件验证基准。没有某档位的样本不能算该档位通过，也不能把无法访问的样本随意记为播放成功。

### 2. EP 定位与 PGC 解析

- 支持验证输入 ep_id 和 `/bangumi/play/ep…` 链接；SS 链接用于取得季度与剧集列表，确认 EP 与季度关系。
- 核对标题、集数、ep_id、season_id、cid、aid / bvid（若提供）及总时长；主剧集、预告和花絮分别标识。
- 新增番剧 PGC 解析入口；不能直接将番剧链接转换为 BV 后沿用普通投稿的播放接口。
- 对照官方剧集顺序与对应内容，验证至少两个 EP 得到不同且正确的 cid；元数据匹配后再验证实际画面与声音。
- 识别接口结果结构、完整正片 / 试看 / 无权播放、实际视频与音频轨；仅 HTTP 200 或接口 code=0 不算播放验收。

接口核对参考 [番剧提取器作者实现](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py#L856)，具体调用与结果结构以验证时平台响应为准。

### 3. 账号和观看资格

复用本机扫码登录和加密保存的 B 站会话，不要求在聊天中提供 Cookie 或密码。分别记录登录有效性、大会员状态、当前集观看资格，以及实际播放结果；最终以平台对当前集的授权和轨道返回为准。

匿名与会员会话分开验证，不把匿名试看结果混进会员成功记录。账号过期、需要大会员、需要另付费、地区限制、未上线、删除 / 下架和临时网络失败分别处理；会员状态有效不能替代单集权限检查。

### 4. 无系统代理实播

| 网络场景 | 设置与条件 | 必须留下的证据 |
|---|---|---|
| D1 直接连接 | 软件使用 direct；平台元数据、播放接口、字幕请求及 CDN 读取不继承系统 / 环境代理；PotPlayer 只连接本机服务 | 请求策略、公开主机名、失败类别，以及原生播放器的源归属、尺寸和持续进度 |
| D2 代理配置隔离 | 在系统或环境存在代理配置的条件下，验证软件 direct 仍不使用它；不主动修改用户系统设置 | 相关请求会话确实忽略代理，而不只是 UI 下拉框显示“直连” |
| D3 国内实际网络 | 若当前验证环境不能代表中国大陆，在当地网络补测，关闭 VPN / 全局隧道后由测试者确认网络条件 | 同网络官网基准与软件实播结果；地区授权限制与连接错误分别记录 |

软件绕过系统代理不等于绕过 VPN 的系统路由，不能把全局隧道下的成功称为“无 VPN 国内播放”。不要求大陆样本一定失败或成功；记录真实结果和未验证环境。

三部正向样本均在 D1 下验证两集，至少每集连续播放五分钟，覆盖声音、画面、持续进度、前后拖动、暂停继续、关闭与资源释放。选其中一部再做一集完整观看；选其中一部在 D2 复测。若出现仅代理下成功，定位是 API、DNS、TLS、CDN、地区限制还是播放器问题，再给出可行性结论。

### 5. 高清档位生效

- 每个目标 EP 记录平台实际返回的轨道 ID、画质标签、编码、宽高、帧率、标称带宽与音频轨，只有实际存在且有权限的轨道可选择。
- 对同一集比较普通 1080P 与会员 1080P+ / 1080P60，或最高可用 SDR 档位；请求档位、实际返回档位和播放器反馈分别记录。
- 核对 PotPlayer 原生反馈的解码尺寸、编码 / 渲染信息、帧率元数据及持续播放；确认整集时长符合元数据，未被换成低清或试看。
- 同分辨率高码率档位不能仅靠宽高判断；需要确认轨道与标称带宽差异，必要时按媒体时间区间采样编码码率。下载吞吐量不作为编码码率证据。
- 4K、1080P60 未被样本实际提供时明确记为“未验证”。不把标称帧率当作掉帧测试，也不把自动检查代替人工声音与音画同步确认。

### 6. 恢复与失败边界

抽测播放地址失效 / 读取中断后的重新解析，确保仍使用番剧接口、同一 EP / cid 和原轨道，保留进度与暂停状态。停止、关闭播放器和取消验证后，迟到结果不得再次启动播放。

若返回 DRM / 加密媒体，记录受保护类型及当前链路不可直接播放的结果，作为独立可行性项，不纳入普通 DASH 支持承诺。第一版验证和界面范围为账号有权观看的普通 SDR DASH；HDR / 杜比视界、DRM 授权组件和永久下载另行评估。

### 7. 阶段通过标准

P8-A 完成后必须形成样本结果表与以下结论，才能进入 P8-B：

1. 三部正向样本各两集的 EP / cid / 标题 / 时长对应正确，实际解码和整集资格一致。
2. 目标样本在软件 direct 下可实播，D2 代理隔离验证通过；国内网络未测试时如实列为尚未覆盖，不能据此承诺国内普遍可用。
3. 至少一个会员高清档位取得并在 PotPlayer 生效，实返轨道和解码参数匹配；不存在的档位不作为成功项。
4. 抽测拖动、暂停继续、恢复位置与清理通过；试看、权限、地区、网络和受保护媒体结果能明确区分。
5. 提供成功范围、失败清单、未覆盖条件和 P8-B 工作量修订。正向样本未达标时继续调查对应问题，不以错误分类通过替代播放通过。

交付脱敏验证记录：网络条件、账号状态类别、EP / cid、目标 / 实际轨道、持续时长、解码证据、故障与清理结果。不保存 Cookie、扫码密钥、完整签名 URL、字幕正文或个人账号标识。初期使用独立测试数据，不改动 0.8.0 稳定包。

## P8-B：选集与收藏界面

### 功能范围

- 在 Qt 前端增加番剧入口，支持 EP / SS 链接，展示作品、季度、正片 / 附加内容和剧集列表。
- 每集显示标题、已上线 / 未上线、会员或另付费标记、观看资格与上次进度；权限以平台结果为准，不能提供本地“强制大会员”开关。
- 显示当前集可用的高清档位、视频编码、音轨和字幕；切换季度 / 剧集后重新查询，避免沿用前一集的轨道和字幕。
- 支持作品收藏、从收藏进入选集；剧集历史与续播使用内容类型 + EP / cid 索引，作品收藏使用 season_id，名称可自定义。
- 复用现有 PotPlayer 原生进度条与专用实例、暂停继续、续期、断点和日志 / 告示；切集清理旧会话，不操作用户其他播放器窗口。
- 数据升级保留现有房间与普通视频收藏 / 历史、设置、加密登录和断点；发行包不携带个人数据。

自动连播 / 跳片头片尾没有纳入本轮必做范围；当前计划先保证手动选集和收藏工作流完整。

### 实现与验收顺序

| 顺序 | 工作 | 验收重点 |
|---|---|---|
| B1 | 将 A 的解析和权限处理接入正式内容模型，加入番剧续期入口与 EP / cid 断点 | 恢复使用正确接口；不会跳到另一集或普通投稿；权限错误有明确结果 |
| B2 | 季度 / 选集 / 画质 / 字幕界面与固定播放状态 | EP / SS 可进入正确位置；快速切集的旧结果被丢弃；125% / 150% / 200% 和最小窗口可操作 |
| B3 | 作品收藏、剧集历史、自定义名称与数据迁移 | 索引去重、改名、删除、重启恢复和升级不丢失原数据；收藏不保存临时播放地址 |
| B4 | 真实会员实播、异常与稳定性回归、便携 EXE 检查 | 重复 A 的正向样本与关键反例；至少一次 30 分钟连续观看或完整单集加切集恢复；最终 EXE 与源码对应；退出清理 |

已交付使用说明、验收记录与 0.9.0 便携包，B1–B4 均完成。整集记录来自正式候选 EXE，发现启动暂停时序问题后的最终 EXE 已重复六集短时恢复测试；具体二进制与验证范围见验收记录。原 0.8.0 包及独立 A 阶段工具保留。
