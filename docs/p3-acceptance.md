# P3 验收记录

版本：0.5.3-p3。Qt Widgets / PySide6 Essentials 6.12.0，Windows 11 x64。

## 已实施

- 使用 P0 已确认的页面、浅色样式与矢量图标；主界面无模拟平台状态。观看、收藏 / 历史、设置与日志接入真实业务。P2 包和 Tk 入口保留。
- GUI-independent LiveRuntime 复用 P1 PlaybackController / PlaybackService / EventCenter 与 P2 PotPlayerAdapter / RelayEndpoint。后台取流及控制返回主线程；停止、暂停和播放器关闭优先于迟到结果。
- 实际直播取流与专用 PotPlayer 播放；当前会话和输入房间独立，收到媒体数据后记录历史。
- 收藏名称可修改，平台 + 数字房间号保持唯一；设置与数据兼容原 v2 格式。
- 固定告示位于滚动区以外，各页一致；普通成功不清除故障。非阻塞提醒、每故障去重、主动停止为 INFO、恢复清除告示。
- 虚拟日志表最多 2,000 条，增量接收、筛选 / 搜索、详情、复制、后台脱敏导出与历史加载。历史错误不会在下次启动重新提醒。

## 验证

验证结果文件位于 .research/p3-*，最终检查包括自动化回归、Qt 原生交互、125% / 150% / 200% 缩放截图、隔离匿名实播和打包自检。实时平台可用性仍取决于主播开播及平台接口；本阶段不替代 P5 的长时间发行测试。

- 151 项自动化测试通过，包含原 P1 / P2 的 127 项与新增的异步取消、暂停 / 继续、播放器关闭、日志导出失败、复制脱敏、数据索引和账号任务等边界检查。启动加载阶段的状态查询最多重试五秒，实际控制命令失败仍立即报告；对应回归检查通过。
- 原生 Qt 交互检查通过；在准确的 1.25 / 1.5 / 2.0 设备像素比下验证通知跨页保留、详情与表格可用、缩小窗口后的布局，截图完成检查。
- 隔离数据、匿名斗鱼 6657 实播取得 1920 × 1080 画面尺寸、持续播放进度与播放器约 30 fps 反馈。画质按接口实际返回显示，不把平台画质名称中的 60 等同于实测帧率。
- 真实 Qt 路径通过开始、手动重连、暂停、继续、受控上游断流自动恢复、停止、停止后重新开始，以及关闭播放器时取消正在准备的结果。原播放器设置指纹保持不变，媒体错误确认框未出现。Qt 计时器在后台操作期间保持响应。
- 便携包独立 EXE 的离线交互与匿名实播检查在构建后执行，结果分别记录在 p3-packaged-ui.json / p3-packaged-live.json。平台未开播作为 WARN 告示验收，不能算成功实播。

## 范围

P4 完整迁移扫码、登录记忆管理、连接检查与画质对比。P3 已提供登录恢复 / Cookie 导入和会话状态信息，未将尚未迁移的按钮做成模拟成功。

独立 PotPlayer 画面尺寸与进度可验证，但没有解码图像自动比对；播放器内的所有行为并非均有公开反馈。后台与全屏提醒可见性、VSR 验证与长期稳定性在 P5 继续。
