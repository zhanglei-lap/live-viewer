# P4 验收记录

版本：0.5.4-p4。Qt Widgets / PySide6 Essentials 6.12.0，Windows 11 x64。

## 功能

- 两平台直播、实际画质选择、收藏与名称、历史、网络方式和 PotPlayer 专用会话沿用 P3 与既有业务模块。
- Qt 扫码窗口接入两平台 QR 流程：生成、等待扫码、等待手机确认、过期、刷新、取消、接收及验证 Cookie。二维码与扫码密钥不落盘，刷新或关闭后的旧结果不导入。
- 分平台登录检查、Cookie 导入、Windows 用户加密记忆与恢复。已记住时，新登录替换旧加密记录；关闭记忆保留内存会话；清除账号取消旧操作并删除保存登录。
- 账号验证与磁盘写入分别调度；凭据写入按平台串行，未开始的旧保存被新清除取代，在执行中的保存后仍会完成新清除。
- 连接检查、匿名 / 登录画质采样、取消、可用档位回填及脱敏诊断报告；诊断任务固定房间和参数，结果不会改变后来编辑的不同房间。
- 重要告示可进入连接检查；账号与诊断成功不覆盖播放故障，取消和主动停止按 INFO 记录。
- 默认源码入口与启动脚本改为 Qt，保留 legacy_main.py 与 P2 / P3 程序包。配置 v2、收藏、历史与原加密登录兼容读取，不读取浏览器 Cookie 数据库。

## 检查

- 180 项自动化测试通过，覆盖扫码刷新 / 取消后的确认、清除中的验证结果、加密恢复、保存 / 删除顺序、保存失败保留内存会话、取消诊断、房间切换与结果回填、字段白名单与脱敏等边界。关闭自动恢复后不会持续显示正在重连，重新开启也不越过主动停止或播放器控制故障。
- 原生 Qt 交互与准确的 125% / 150% / 200% 缩放检查通过，检查及截图覆盖账号页、扫码窗口、固定通知、诊断结果、报告导出与日志。
- 两平台真实二维码申请和等待扫码轮询、取消经过匿名实测；没有用真实账号或手机完成确认。确认、验证和 Windows 加密后的结果处理用合成登录测试，手机确认与账号画质仍需本机实际账号复测。
- 斗鱼 6657 的真实匿名连接检查和 FLV 采样通过，未导入账号时正确跳过账号对比。B 站 6 的匿名 PotPlayer 播放取得 1280 × 720 尺寸与持续进度，接口实际 qn=250。B 站 35 在前期接口检查时未开播，正确显示 WARN；最终独立 EXE 检查时已开播，也取得 qn=250、1280 × 720 与播放进度。
- 真实 Qt 播放回归通过手动重连、稳定本地地址、暂停后继续、受控上游断流自动恢复、主动停止、停止后播放、关闭播放器时取消后台取流；Qt 保持响应，原 PotPlayer 设置不变，未出现媒体错误确认框。
- 最终便携包在隔离数据目录通过独立 EXE 的交互、合成加密登录、扫码组件、两平台真实二维码 / 轮询、斗鱼 6657 与 B 站 35 / 6 实播及停止。ZIP 完整性、程序与源码一致、原播放器设置不变均通过；包内排除个人配置、Cookie、加密登录、日志和 PotPlayer 本体。

检查记录位于 .research/p4-*。二维码不会作为真实验证截图或返回数据保存；界面截图使用合成挑战。

## 范围

P4 完成 Qt 现有直播工作流迁移。没有自动核验解码图像或声音，采样不代表画面延迟。斗鱼账号有效性仍未独立验证，最终画质由平台返回。

P5 继续 NVIDIA VSR、30–60 分钟稳定性、受控恢复、后台与全屏通知及正式发行验收。P6 起做 B 站点播。
