# 0.5.0：原生播放窗口与直连

- 播放窗口交由 mpv 管理，启用内置 OSC 控制条，移除 Tk 播放外壳；全屏仅保留视频和按鼠标活动显示的控件。
- 增加本次观看的缓存进度条，支持缓存内点击 / 拖动回看、左右键 5 秒移动、L 回到直播；暂停 / 继续、音量、静音与全屏使用成熟引擎控件。直播不具有整场录像进度。
- 默认平台直连，可选择系统 / 环境代理；扫码、接口、CDN 统一策略。本机 mpv 连接独立绕过代理，保持 HTTPS 证书校验。
- 直连优先 IPv4，失败后保留 IPv6 回退，避免部分网络逐个等待不可达 IPv6 地址；不修改系统网络设置。
- 加入当前房间连接检查及脱敏报告，区分 DNS、TLS、代理、超时、房间接口和 CDN 失败。
- 首次播放复用刚取得的接口结果及会话，避免在本机 HTTP 请求中重复解析；先检查 CDN 返回 FLV 数据再启动播放器，后续重连仍重新签名取流。

更新时关闭旧程序，完整解压新 ZIP，保留原 data 文件夹。不要只替换 EXE；runtime/mpv/live-controls.lua 是新版直播控制条的一部分。个人设置与加密登录不放入发行 ZIP。

本次验证（2026-10-07）：88 项自动化测试通过；斗鱼 6657 和 B 站 1883358196 匿名实播、全屏、暂停 / 继续、回到直播和关闭取消重连均通过。底部按钮及缓存点击 / 拖动另做原生引擎交互验证。打包后的 EXE 在失效环境代理下完成匿名取流、二维码生成、静音实播和受控断流恢复自检，结果 success=true，恢复后播放项仍为一个。便携 ZIP 已核对引擎摘要和脚本一致性，未包含个人设置或登录。

匿名当前返回：斗鱼实际 rate=4、蓝光 4M、1920×1080 / 30fps；B 站 1883358196 实际 qn=250、1280×720 / 30fps。此为本次房间与网络的观察结果，不代表登录后的最大画质或中国大陆各运营商表现。新播放器长时间声音与音画同步仍需人工验收。

检查报告位于 .research/packaged-v050-check.json、native-ui-v050-douyu.json、native-ui-v050-bilibili.json 和 release-v050-artifacts.json。大陆朋友的实际网络仍需使用直连模式复测。技术链路详见 playback-and-network.md。
