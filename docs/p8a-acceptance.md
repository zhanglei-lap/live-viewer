## 网络、账号与人工确认

- 用户在可见独立窗口用手机扫码确认，账号只留在内存；未读取浏览器 Cookie 数据库或稳定版 DPAPI 登录。
- 真实登录状态为 authenticated，大会员状态 active，六集返回整集资格；资格仍由 PGC 响应和实际轨道决定。
- 测试工具进程中设置不可达环境代理 `127.0.0.1:9`；API / CDN 会话 `trust_env=false`，合并代理数 0，实际取流与原生播放通过。没有修改 Windows 系统代理。
- 用户在窗口确认：中国大陆网络，已关闭 VPN / 全局隧道。此项是使用者对测试网络的确认，不能从 CDN 主机名或 direct 选项自动推断。
- 用户在聊天明确确认：官网同账号整集资格和高清档位一致；六集内容、声音、画面和音画同步正常，普通 1080P 也正常。

## 恢复、清理与探针修正

每个正向样本覆盖：向前 / 向后拖动，暂停，修改签名地址使真实 CDN 拒绝访问，本机 Range 请求触发重新解析，核对 EP / cid / 轨道、文件大小与前 4 KiB 摘要不变，保留原生暂停位置和会话，再继续播放。退出后专用进程结束，缓存和本轮配置移除，监听器与控制线程停止。可复用的播放器引擎副本保留，不是观看缓存。

首轮完整观看正常自然结束，但探针随后对同一个双轨实例再次调用 open；P7 适配器明确要求双轨使用新专用实例，因此后续检查报 `reopen_after_end` 失败。已修正为关闭旧实例并验证其资源释放，再建立新实例。首集的完整观看记录保留，五分钟控制补测通过；修正后的匿名结尾补测及最终 EXE 三个首集结尾重开均通过。快速跳转到结尾的补测未计作完整观看。

## 未覆盖条件

真实 DRM 媒体、另付费 / 账号无权内容、其他地区限制、未上线与下架内容尚无实际账号样本；相应失败分类主要由隔离数据验证。HDR / 杜比视界、60fps、PGC CC 字幕、其他季度及完整正式选集 / 收藏界面不作为本阶段通过项。实际返回加密媒体时停止普通 DASH 链路，不提供解密或授权绕过。

P8-B 仍需将独立解析适配到正式播放与断点模型，以内容类型 + EP / cid 记进度，以 season_id 收藏作品；接入季 / 集 / 画质 / 字幕 UI、统一通知与数据升级，再做正式包回归。实施范围见 [P8 计划](p8-bangumi-plan.md)，工具操作见 [P8-A 使用说明](p8a-usage.md)。
