# 桌面原型验证

日期：2026-10-05；2026-10-06 补充斗鱼修复验证。目标 Windows 11 25H2。

本页保留测试原型阶段的记录。用户随后确认基础测试无问题；0.2.0 的房间管理、加密登录记忆和 EXE 验证见 [新版验收](release-0.2.0.md)。

## 已验证

- Python / Tkinter 窗口正常初始化，界面带垂直滚动，可适配较小窗口。
- 24 项自动化测试通过：输入链接归一化、Cookie 域名/过期过滤、B 站实际画质、斗鱼实际档位、流容器采样、CDN 范围、失效登录处理、HTTP 转发与报告无凭据；新增斗鱼短号转换、真实房间号签名、停播判断、CDN 重定向、备用线路不降档、沿用 Cookie 会话，以及已经输出 FLV 时不拼接备用流的检查。
- 真实匿名调用：B 站 35 返回实际房间 21622811，原画请求返回 qn=250；流容器为 H.264、1280×720、30 fps。
- 真实匿名调用：斗鱼 36252 原画请求返回 rate=4（蓝光4M），流元数据为 H.264、1920×1080、30 fps。
- 更正初次斗鱼 6657 调查：直接请求短号导致错误。现已从网页提取真实房间号 6979222，用真实房间号签名和取流；匿名返回 rate=4（蓝光4M），短时容器样本为 H.264、1920×1080、30 fps。
- 斗鱼 6657 与补充样本 3168536 的 CDN 重定向适配后读取成功；HTTPS 证书与目标域名校验保持启用。6657 本机转发返回 HTTP 200、有效 FLV 文件头。
- 同日第二次修复：6657 公开接口返回 edgesrv.com，该线路在本机发生 TLS 连接失败；工具现可根据 cdnsWithName 重新签名请求备用 CDN。用真实公开接口指定 edgesrv 首线路后，短时采样与本机转发均自动切至 hw-h5 成功，实际 rate 保持 4。此验证未使用账号 Cookie；登录会话只做了合成 Cookie 的自动化验证，不能代替用户账号验收。
- B 站直播经工具的 127.0.0.1 HTTP 转发后返回 HTTP 200 和有效 FLV 文件头。
- 已用用户提供的 `D:\potplayer\PotPlayerMini64.exe` 启动实际播放；PotPlayer 已请求本机地址，转发计数递增。
- PotPlayer 切到前台后，屏幕捕获确认直播画面正常显示；此前 PrintWindow 截图不能捕获硬件渲染视频，不能据其黑色区域判定未播放。
- 工具窗口截图已检查，操作区、对比结果、播放状态与报告按钮可见。

- 新增：无后缀 Netscape 文本可导入，Edge/Chrome SQLite 数据库明确提示；本机粘贴 Cookie 支持与凭据不回显检查通过。
