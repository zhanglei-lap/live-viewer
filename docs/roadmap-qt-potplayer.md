# Qt / PySide6 与 PotPlayer 开发路线

初始规划日期：2026-10-10；番剧阶段更新：2026-10-13（P8-A / P8-B 完成）；抖音阶段更新：2026-11-11（P9 完成）。当前版本：0.10.0（P9），原 0.9.0 / 0.8.0 稳定包保留。采用 Qt / PySide6 前端，以外部 PotPlayer 为主播放器；下表工作量保留原规划估算。

## 产品与技术边界

- 主程序负责平台取流、登录、收藏、历史、网络诊断、播放会话及事件记录；PotPlayer 负责播放窗口、进度条、全屏和渲染增强。
- 前端使用 PySide6 Qt Widgets 与统一样式；先提供清晰的浅色界面、导航、列表、播放状态卡片及固定通知区。Qt 提供布局与高 DPI 基础，视觉规范仍单独设计。[Qt for Python](https://doc.qt.io/qtforpython-6/)、[高 DPI 文档](https://doc.qt.io/qt-6/highdpi.html)
- 复用已验证的接口适配、直连 / 代理策略、IPv4 优先、HTTPS 校验、扫码流程和 Windows 用户加密登录。Qt 前端迁移不重写这些网络能力。
- 网络和播放器操作在后台执行，界面更新统一返回 Qt 主线程。播放状态、日志和通知使用同一个事件入口。
- 日志保存操作、状态变化、每次重试及异常；持续变化的流量 / 帧率等统计按需汇总为 DEBUG。记录时间、级别、事件代码、来源、房间 / 视频标识和播放会话；过滤 Cookie、扫码密钥及签名 URL。
- PotPlayer 保持独立窗口。播放器控制只作用于本工具创建或明确关联的会话。其内部没有公开反馈的事件不能假定全部可捕获。
- 点播第一版限定普通 BV / AV 投稿和账号可访问的标准媒体，不以“任意 B 站内容均可导出”为验收目标。

## 界面规划

| 页面 / 区域 | 主要内容 |
|---|---|
| 观看 | 左侧收藏与历史；右侧平台、链接 / 房间、画质及主要操作；固定的当前播放状态 |
| 通知区 | 全页面统一位置；短标题、原因、必要动作、可展开技术详情；不被普通成功消息覆盖 |
| 账号 | 按平台显示登录状态，扫码、导入、清除和加密记忆 |
| 设置 | PotPlayer 路径与会话配置、网络模式、恢复策略、通知与日志设置 |
| 日志 | 时间、级别、来源、房间 / 视频、内容；筛选、搜索、详情、复制和脱敏导出 |
| 诊断 | 当前连接检查、画质对比、诊断报告；长域名和统计信息在详情呈现 |
| 点播 | P6 起接入 BV / AV、分 P、轨道选择和视频收藏 |
| 番剧 | P8-B 接入 EP / SS、季度与选集、单集权限、作品收藏、剧集历史与续播 |

第一版统一浅色样式和可读性。深色主题、封面卡片及动画在基础布局稳定后再评估，避免让装饰效果阻塞功能迁移。

## 事件与提醒规则

| 事件示例 | 等级 | 展示方式 |
|---|---|---|
| 保存、登录成功、开始解析 | INFO | 日志 + 简短通知 / 操作状态 |
| 用户主动暂停、停止或关闭播放器 | INFO | 日志 + 醒目的当前状态；不使用错误弹窗 |
| 房间未开播，阻止本次启动 | WARN | 日志 + 常驻告示，可换房间或重新检查 |
| 一条线路失败但仍有备用线路 / 重试 | WARN | 每次尝试记录；显示切换 / 重连状态，不逐次弹确认框 |
| 没有可用线路、播放器不能启动、恢复最终失败 | ERROR | 日志 + 常驻错误告示；首次 / 最终失败强提醒，提供重试、网络检查和日志入口 |
| 应用无法继续运行 | CRITICAL | 保存诊断，明确阻断提示 |

等级与提醒强度分开判断：未开播不属于程序崩溃，但用户发起的播放无法完成，需要醒目告知。恢复成功后清除当前故障告示，历史错误仍保留。

PotPlayer 全屏、工具在后台时，评估 Qt 托盘 / 系统通知与非阻塞提醒窗口的实际可见性。Windows 勿扰可能限制系统通知，因此验收还要核对未读提醒和主界面故障状态，不能只凭调用通知接口成功判定用户已看见。

## 完成与实施约定

- 每阶段完成对应功能与有意义的检查，再进入下一阶段；记录成功结果和仍存在的兼容性限制。
- P0 的界面原型先做成可查看结果，随后按确定的规范实施页面；不把“换框架”当作视觉设计已经完成。
- 业务接口、播放器行为、日志记录、当前状态和提醒分别验收，尤其检查异步结果、重试与用户停止之间的先后关系。
- Windows 包装策略在 Qt 原型阶段验证，在 M2 前完成；依据 [Qt / PyInstaller 部署说明](https://doc.qt.io/qtforpython-6/deployment/deployment-pyinstaller.html) 收集所需组件与许可证。
- 原稳定版本及个人数据保留；新前端的数据升级应可验证，发行包不包含个人设置、Cookie 或登录态。
