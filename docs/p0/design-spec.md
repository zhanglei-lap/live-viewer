# P0 页面、视觉与事件规范

日期：2026-10-10。载体：PySide6 / Qt Widgets 6.12.0 原生交互原型。正式程序仍为 0.5.0。

## 交付与边界

P0 包含页面结构、视觉规范、可运行交互原型、事件结构、播放状态定义与 PotPlayer 控制验证清单。所有播放、账号和连接为模拟，不访问平台、不启动 PotPlayer、不加载已有收藏或账号。演示日志位于内存；用户主动导出才生成 JSON。

源码位于 prototypes/p0，独立环境为 .venv-p0。真实日志、状态控制、播放器和登录分别在 P1–P4 接入。打包验证仅证明 Qt 原型可部署，不表示正式版迁移已经完成。

## 页面结构

| 区域 | 位置与内容 | 原则 |
|---|---|---|
| 导航 | 固定左侧：观看、账号、设置、活动日志、诊断 | 核心入口可直接访问 |
| 页面标题 | 顶部标题与用途说明 | 不与主要操作争夺注意力 |
| 统一通知区 | 标题下方，所有页面共用；短标题、原因、动作、折叠详情 | 不随页面内部滚动消失；普通成功消息不覆盖故障 |
| 观看 | 收藏与搜索；当前播放状态、操作、房间输入、观看选项 | 当前会话与待打开输入分开 |
| 账号 | 分平台状态、扫码、导入、清除、登录记忆 | 账号任务不接管播放状态 |
| 设置 | 播放器、网络、恢复 / 通知、日志 | VSR 显示待验证，不假定已经激活 |
| 活动日志 | 等级筛选、搜索、表格、详情、导出 | 保存来源与会话关联 |
| 诊断 | 分阶段连接检查与公开技术信息 | 转发成功不代替实际解码验证 |
| 底部摘要 | 最后一次活动与简短反馈 | 不能代替播放状态或故障通知 |

点播在 P6 增加页面与目标标识。P0 不把点播显示成可用功能。

## 事件结构

event.schema.json 定义版本 1，原型模型按同一结构生成示例。P1 扩展时明确迁移版本。

| 字段 | 用途 |
|---|---|
| schema_version / event_id | 结构版本和唯一事件 |
| occurred_at | 含时区时间；显示使用 Asia/Hong_Kong |
| level | DEBUG / INFO / WARN / ERROR / CRITICAL |
| code / source | 稳定代码与来源；不从中文关键词猜等级 |
| message | 简短可读内容，不含凭据或整条签名 URL |
| impact | none / degraded / start_blocked / interrupted / app_blocked |
| presentation | log / toast / banner / strong；实际通知受偏好与状态约束 |
| target / session_id | 业务目标与播放会话 |
| dedupe_key | 按会话与事件类型分组通知 |
| details | 仅公开域名、阶段、原因代码、次数、网络模式等允许字段 |
| demo | P0 为 true，正式事件为 false |

全部业务操作、状态变化、每次重试、成功和异常进入统一入口。每帧接收、每个输入字符或每次界面刷新不生成业务日志；性能统计按需汇总到 DEBUG。P1 的持久化日志、当前状态和通知共同消费这些事件。

## 分级通知

| 情况 | 等级 / 影响 | 呈现 |
|---|---|---|
| 保存、登录成功 | INFO / none | 日志与短反馈，不能覆盖故障 |
| 主动暂停 / 停止 / 关闭 | INFO | 大字号当前状态，自动恢复退让，不作为错误弹窗 |
| 未开播 | WARN / start_blocked | 常驻告示，可换房间，不解释成程序崩溃 |
| 单线路异常，有备选或正在重试 | WARN / degraded 或 interrupted | 每次记日志，不逐次弹确认框 |
| TLS 失败且没有可用线路 | ERROR / start_blocked | 固定告示，详情与检查入口；同会话同类故障首次强提醒一次 |
| 尝试用尽 | ERROR / interrupted | 明确恢复失败，停止自动尝试；最终失败强提醒一次 |
| 应用无法继续 | CRITICAL / app_blocked | 保存诊断；P1 实现阻断提示 |

等级与影响是两个维度：未开播是 WARN，但它阻止用户本次操作，因此仍醒目告知。主动停止是 INFO，当前状态同样明显。

切换页面、登录成功和普通 toast 不清除播放故障。用户确认弹窗只表示已看见，不能表示故障已解决。恢复、开始新会话或主动结束会话按状态规则清理告示，日志保留历史。

P0 使用非阻塞独立提醒窗口演示 ERROR；设置可以关闭强提醒而保留告示与日志。正式后台 / 全屏通知在 P5 验证实际可见性，不能把通知接口调用成功当作用户已看见。

## 播放状态

| 状态 | 含义 | 主要动作 |
|---|---|---|
| idle | 尚未发起播放 | 开始 |
| resolving | 查询房间 / 账号 / 媒体 | 取消、停止 |
| connecting | 发送播放器请求 | 取消、停止 |
| playing | 得到足够播放证据 | 暂停、停止、回到直播 |
| paused | 用户暂停 | 继续、停止；抑制自动恢复 |
| reconnecting | 意外断流重试 | 停止恢复、手动重试 |
| stopped | 用户停止 / 关闭 | 重新开始，不自行恢复 |
| unavailable | 目标未开播 / 不可用 | 换目标、重新检查 |
| error | 启动或恢复失败 | 重试、诊断、日志 |

请求已发送或转发了字节都不足以称为“已验证播放”，PotPlayer 的证据由 P2 验证。P0 明确显示“演示播放中”。

~~~mermaid
stateDiagram-v2
    [*] --> idle
    idle --> resolving: 开始
    resolving --> connecting: 媒体就绪
    resolving --> unavailable: 未开播
    resolving --> error: 查询失败
    connecting --> playing: 播放确认
    connecting --> error: 启动失败
    playing --> paused: 用户暂停
    paused --> resolving: 继续直播
    playing --> reconnecting: 意外断流
    reconnecting --> playing: 恢复成功
    reconnecting --> error: 尝试结束
    resolving --> stopped: 用户取消
    connecting --> stopped: 用户停止
    reconnecting --> stopped: 用户停止
    paused --> stopped: 用户关闭
    playing --> stopped: 用户停止
    stopped --> resolving: 重新开始
    error --> resolving: 重试
    unavailable --> resolving: 换目标或重试
~~~

会话使用 ID，异步操作使用有效代次。停止、关闭、切换使旧任务失效；迟到结果只记 DEBUG，不弹错、不修改新会话或重新开播。账号任务使用独立目标。

## PotPlayer 控制验证清单（P2 入口）

| 探针 | 验证内容 | 失败处理 |
|---|---|---|
| 安装与版本 | 精确路径、64 位与命令行能力 | 提示选择程序，不猜任意路径 |
| 专用实例 | 关联本工具进程、窗口、媒体地址 | 不操作用户其他播放器 |
| 播放请求 | 本机地址、标题、打开行为和状态读取 | 不把启动进程当成播放成功 |
| 停止 / 关闭 | 同步停止转发和播放器，取消恢复 | 用户意图优先 |
| 旧源替换 | 连续重连不增加旧项，切换房间正确 | 记录版本和清理 / 替换兼容性 |
| 错误模式 | 专用配置验证 OSD 与模态弹窗行为 | 不靠反复确认弹窗伪装成稳定恢复 |
| 消息超时 | 忙碌、窗口关闭、权限差异 | 界面保持响应，给出事件 |
| 受控断流 | 中断本工具转发，恢复同房间和档位 | 不关闭系统网络，不直接拼接不同 FLV |
| 暂停 / 停止 | 每个状态下抑制不需要的重启 | 忽略旧任务 |
| 背景 / 全屏 | 提示可见性、进入诊断、未读状态 | 不假定系统通知必然可见 |

此前仅核对了命令行和资源。P0 不调用 PotPlayer 控制接口；P2 以实际操作结果完成探针。
