# 本地直播 P0 · Qt 交互原型

所有房间、账号、连接和播放状态为演示数据。原型不访问平台、不启动 PotPlayer、不接受真实 Cookie，不加载或修改正式版数据。

完整解压便携包并保留 runtime 文件夹，双击 LiveViewer-P0.exe，无需安装 Python。

## 怎样预览

1. 切换“观看、账号、设置、活动日志、诊断”五个页面。
2. 点击“开始播放”查看模拟解析 / 连接 / 播放；点击“停止”查看大字号状态和 INFO 日志。
3. 右上角选“未开播”并点击“演示”，查看固定 WARN 告示。
4. 选“TLS 连接失败”，查看错误告示和一次独立提醒。确认不消除当前故障；技术详情可展开。
5. 选“登录成功不覆盖故障”，普通活动记录不改变故障。
6. 选“重复同类故障”，每次进入日志，同会话不重复弹窗。
7. 选“重连后恢复 / 重连最终失败”，每次尝试记日志；恢复中按“停止”应保持停止状态。
8. 日志支持等级 / 文字筛选、选中查看详情、主动导出演示 JSON。关闭后清空演示内存日志。
9. 扫码区仅为布局示意，可用“模拟登录成功”检查状态变化。设置中的演示恢复和强提醒选项可切换。

原型较窄时内容可滚动，告示仍固定在顶部。后台 / 全屏通知、真实扫码与播放在后续阶段接入。

## 源码运行

项目根目录执行：

~~~powershell
.\.venv-build\Scripts\python.exe tools/setup-p0.py
.\.venv-p0\Scripts\python.exe prototypes/p0/app.py
~~~

环境位于项目 .venv-p0。构建依赖通过 tools/setup-p0.py --build 安装，tools/build-p0.py 生成便携包。

设计规范与事件结构位于 docs/p0/design-spec.md、docs/p0/event.schema.json。P1 才接入正式日志和状态控制。
